FOLDER FOTO KEGIATAN SEKOLAH
=============================
Letakkan foto kegiatan sekolah di folder ini dengan nama:
  foto1.jpg
  foto2.jpg
  foto3.jpg
  foto4.jpg
  foto5.jpg

Format: JPG atau PNG
Ukuran ideal: 1280x720 px (landscape/horizontal)
Ukuran file: maksimal 2MB per foto

Foto akan tampil sebagai auto slider di Monitor TV ruang guru.
Ganti caption di file monitor-tv/index.html pada array daftarFoto.
